# State minimum wage & retail/food-service employment — a difference-in-differences study

Causal-inference analysis of the **January 1, 2024 round of state minimum-wage
increases** (22 states) and their effect on retail and leisure-&-hospitality
employment, using FRED/BLS state-level payroll data. Card–Krueger-style design,
built with the identification checks that a single regression skips: parallel-
trends diagnostics, an event study, a placebo/falsification test, randomization
inference, and robustness to the control-group choice.

**Headline result:** no measurable employment effect. Best estimate for retail is
≈ −0.6% (about −39,000 jobs across the treated states), 95% CI ≈ −86k to +8k, and
the placebo test shows the design produces "effects" that size at random dates.
Read as a precise zero. Full interpretation in **[MEMO.md](MEMO.md)**.

## Findings at a glance

| Check | Result |
|---|---|
| Headline DiD, retail | −0.56% (p = 0.10); with region×month FE −0.19% (p = 0.64) |
| Headline DiD, leisure & hospitality | +0.20% (p = 0.59) |
| Placebo outcome (total non-farm) | −0.17% (p = 0.48) — no effect, as it should be |
| Event study | flat pre-trend for retail; slow −0.8% drift by month 30, partly pre-existing |
| Placebo (fake policy dates) | real estimate at the 76th percentile of the placebo distribution; RI p = 0.76 |
| Robustness (36 specs) | retail estimate stays within −1.0% to +0.3%; significant in only 3 of 18 baseline specs |
| Parallel trends (formal joint test) | rejected in every spec — see caveats; pre-period gaps for retail are < 0.4 log points |

## Method

- **Treatment:** 22 states raising the statewide minimum on 2024-01-01, split
  into *legislated* step increases (DE, HI, IL, MD, NE, NJ, NY, RI) and smaller
  *indexed* COLA increases. FL/NV/OR (mid-2024) excluded from both groups.
- **Control:** `strict` = 21 never-treated federal-\$7.25 states (+ WV).
  `broad` adds NM and VA (last raised Jan 2023). `border` = non-treated states
  sharing a land border with a treated state.
- **Estimator:** `y ~ treat·post | state + calendar-month`, SEs clustered by
  state (`pyfixest`). Because every treated state switches on at the same date,
  this is not a staggered design and TWFE carries no negative-weighting problem.
- **Event study:** `y ~ i(event_time, treat, ref=-1) | state + month`, leads to
  −17, lags to +30.
- **Placebo:** the design is re-anchored to fake dates and estimated on data
  strictly before the real policy, so a genuine 2024 effect cannot leak in.
  Sliding fake dates across 2018–2023 give a placebo distribution for
  randomization inference.
- **Robustness:** control group (×3), treatment definition (×3), fixed effects
  (state+month vs. + division×month), estimation window (2022-07 vs. 2021-01),
  COVID-months dropped or kept.

## Data

State-level "All Employees" series from FRED (public CSV endpoint, no API key
needed; set `FRED_API_KEY` and pass `--api` to use the JSON API instead):

- Retail trade, SA: `SMS{FIPS}000004200000001`
- Leisure & hospitality, SA: `{ST}LEIH`
- Total non-farm, SA: `{ST}NA`

50 states, 2015-01 to 2026-07. The raw pulls and the built panel are committed
under `data/` so the analysis is reproducible offline; `--refresh` re-pulls them.

## Reproduce

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run_all.py            # or: python run_all.py --refresh
```

Outputs: tables in `output/*.csv`, figures in `figures/*.png`, interpretation in
`MEMO.md`. Runtime ≈ 2–3 minutes (the sliding placebo rebuilds the panel per date).

## Caveats

The formal joint test of pre-period parallel trends is rejected in every
specification. For retail the economically meaningful pre-period deviations are
tiny (< 0.4 log points) and the region×month and border-control specs — which
address the most likely confounder, post-2021 migration toward low-wage Sun Belt
states — move the estimate *toward* zero. But this design would misread a
genuine divergence in treated-state employment trajectories as a policy effect,
and it says nothing about hours, scheduling, hiring standards, prices, or firm
entry/exit. See MEMO.md for the full list.
